Importante sobre o WhatsApp

O formato de figurinha sonora é gerenciado pelo próprio WhatsApp. Este site exporta clipes de vídeo com áudio e um ZIP de organização; o ZIP não é um pacote que o WhatsApp importe diretamente. Para criar a figurinha sonora, abra o WhatsApp, use Figurinhas → Criar, escolha o clipe exportado e finalize no editor nativo. A função ainda pode não estar liberada para todas as contas.
